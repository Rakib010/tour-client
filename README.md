# Tour Client

Frontend for a Bangladesh tour booking platform. Browse tours, read destination guides, book trips, and pay with SSLCommerz.

## Features

- **Home** — banner, stats, categories, featured tours, testimonials, and blog highlights
- **Tours** — searchable tour list with filters (division, category, date, guests)
- **Tour details** — overview, cost, itinerary, images, and booking CTA
- **Categories** — browse by tour type (Adventure, Beach, Heritage, and more)
- **Divisions** — browse tours by Bangladesh division
- **Tour Guide** — destination guides with how to go, where to stay, budget, and related places
- **Auth** — register, login, Google login, logout, and password reset
- **Booking** — create a booking and redirect to SSLCommerz checkout
- **Payment pages** — success, fail, and cancel screens after payment
- **Comments & ratings** — 1–5 star reviews on tour details
- **User dashboard** — overview, bookings, profile, favorites, and support
- **Admin dashboard** — analytics, tours, divisions, tour types, users, and bookings
- **Theme** — light / dark mode
- **Responsive UI** — works on mobile, tablet, and desktop
